## 🚀 Что делает бот

Бот автоматически определяет язык и выполняет соответствующие действия:

### 📝 Русский текст → Английский перевод
- Отправьте любой русский текст
- Получите английский перевод с объяснениями
- Примеры: "Привет как дела" → "Hello how are you"

### 🔤 English text → Choose action
- Send English text to the bot
- Choose "Grammar Check" or "Translate to Russian"
- Get detailed feedback and explanations

```
Вы: Привет, как дела?
```
