# 🔑 Как получить токен для SK_english_bot

## 📱 Вариант 1: Если бот уже существует

1. **Откройте @BotFather в Telegram:** https://t.me/BotFather
2. **Отправьте команду:** `/token`
3. **Выберите ваш бот:** `SK_english_bot` (если он есть в списке)
4. **Скопируйте токен** - он выглядит так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

## 🆕 Вариант 2: Создать нового бота

Если SK_english_bot не найден или недоступен:

1. **Откройте @BotFather:** https://t.me/BotFather
2. **Отправьте:** `/newbot`
3. **Введите имя:** `SK English Bot`
4. **Введите username:** `SK_english_bot` (или `YourName_english_bot` если занят)
5. **Скопируйте токен**

## 🔧 Настройка токена

1. **Откройте файл .env:**
   ```bash
   nano .env
   ```

2. **Замените строку:**
   ```
   BOT_TOKEN=your_bot_token_here
   ```
   **на:**
   ```
   BOT_TOKEN=ваш_реальный_токен_здесь
   ```

3. **Сохраните файл:** `Ctrl+O`, затем `Ctrl+X`

## 🚀 Запуск бота

```bash
# Запустить бота
./start_bot.sh start

# Проверить статус
./start_bot.sh status
```

## ❓ Проверка работы

1. **Найдите вашего бота в Telegram:** по username (например `@SK_english_bot`)
2. **Нажмите "Start" или отправьте** `/start`
3. **Бот должен ответить** приветственным сообщением

## 🔍 Диагностика проблем

Если что-то не работает:

```bash
# Полная диагностика
./diagnose.sh

# Просмотр логов
./start_bot.sh logs

# Проверка здоровья
./start_bot.sh health
```

## ⚠️ Важные моменты

- **Токен нужно держать в секрете** - не публикуйте его
- **Один токен = один бот** - нельзя использовать один токен для разных ботов
- **Если токен украли** - создайте нового бота или сбросьте токен через @BotFather
- **Проверьте права** - убедитесь что вы админ бота

## 🆘 Если ничего не помогает

```bash
# Экстренная переустановка
./start_bot.sh stop
rm -rf bot_env logs/*
./install.sh
```

После получения токена бот будет работать **24/7** с автоматическим восстановлением! 🎉
